# data-name 与 data-uid 标注规划

> 依据：data-name 技能（~/.dsh/skills/data-name），但**有一处有意改动**，见最后一节。

## 一、两个属性：角色 + 唯一（方案 B）

| 属性 | 管什么 | 例子 | 唯一性 |
| --- | --- | --- | --- |
| `data-name` | **语义角色**（这是什么东西） | `instance-card` / `row-menu` / `source-badge` | **允许重复** ✓ 同类共用 |
| `data-uid` | **这一具体个**（是哪一个） | `k3f9a2x1`（8 位 base36） | **必须唯一** ✓ 全页不重复 |

人读路径看 `data-name`；要**精确指到一个**时用 `data-uid`；两者可以叠成复合选择器（合法 CSS）：

```css
span[data-name="source-badge"][data-uid="m7q2w9de"]    /* 运行中分组那个 */
span[data-name="source-badge"][data-uid="k3f9a2x1"]    /* 已停止分组那个 */
```

**为什么是两个属性而不是合成一个**（2026-10-15 定）：
- 合成 `name#uid` 会让**按角色精确匹配失效** ✗（`[data-name="instance-card"]` 不再命中，只能退到前缀 `^=`，语义变松）
- 两个属性下，CSS 选择器**照旧精确匹配** ✓；唯一性由第二个属性承担 ✓
- 代价是拾取工具要多认一个属性 —— 而**那个工具是我们自己的**
  （`~/.agents/skills/data-name/userscript.user.js`，已改：有 `data-uid` 就拼成复合选择器）
## 二、uid 那一段的三条硬约束

1. **必须稳定** ✗ —— 同一个元素在两次渲染、两次刷新之间必须是**同一个值**。
   真正「每次渲染随机生成」的值是**没用的**：工具读到它，下一次刷新就变了，等于指不到。
   所以「随机哈希」的正确理解是：**长得随机、取值确定** ✓
2. **取值确定**：由该元素的**语义路径**算出，例如
   overview|card|profile:web-dev|menu-item|archive → k3f9a2x1
   同一元素永远同一串；不同元素撞串概率可忽略（8 位 base36 约 2.8e12）。
3. **不许用位置算** ✗ —— 不许拿索引、序号、「第几个」参与哈希：
   列表顺序会变（已停止组刚改成按最近改动排序），用位置算出的 uid 会**跟着顺序变**，比没有还糟 ✗
   该用该项自己的键（profile 名、端口、setting key…）。

## 三、标注范围

**要标**：卡片（实例卡 / 归档行）、卡片里每个字段（标签与值）、每个按钮与菜单项、下拉触发器、
徽标（含分组来源徽标）、对话框与其内部控件（输入框 / 确定 / 取消）、设置页每个条目与其控件、
日志页的来源下拉与每个来源项、日志框、侧栏导航项、设置页左索引项。

**不标**：纯布局容器、纯装饰元素、动态生成的临时节点 ✗

## 四、命名（沿用技能口径）

- kebab-case ✓
- 表达**角色**，不表达位置 ✗（row-menu 而不是 menu-3）
- 层级扁平：需要直接引用的那层才标 ✓

## 五、与技能原文的差异（有意改动，记下来免得后人对不上）

技能原文写着「不要添加 index/id/序号」，并让重复项共用 data-name。
本次按使用者要求**改动这一条**：重复项除了共用的 data-name，**各自再带一个唯一的 data-uid**。
原因：使用者的元素拾取工具对同角色的两个元素给出了**完全相同的路径**
（span[data-name=source-badge] 同时命中「运行中分组」与「已停止分组」两处），
只靠 data-name 加第 n 个匹配，工具与人**都指不准** ✗

合成写法进一步简化了这件事：工具只认 data-name，一眼就拿到唯一值 ✓

## 六、验收（自己量，不看代码）

1. **唯一性**：在每个界面状态下枚举所有带 data-uid 的元素，**零重复**
   （要覆盖：初始页、展开行菜单、打开对话框、设置页、日志页、展开归档区）
2. **稳定性**：同一状态刷新两次各抓一遍，同一个语义元素两次 uid 相同
3. **顺序无关**：把已停止组顺序变一下再抓，各元素 uid 不变（专防「拿位置算 uid」）
4. **可读性**：给出「语义路径 → uid」对照表；任取一个 uid 能说出它是什么
5. **不干扰现有验收**：run-acceptance 判定项全过（新增属性不许改变几何与交互）
