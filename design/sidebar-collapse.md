# 可折叠侧边栏

## 0 现状

侧栏固定 190px。390 宽的窗口里它占 48.7%，主区只剩 200px：关于页的值列逐字竖排，总览卡片名只剩 8px，日志正文只剩时间戳加一个字母。

## 1 宽屏（≥1024）

- 侧栏两种形态：展开（190px，图标加文字）与收起（56px，只有图标，悬停出名字）。
- 顶栏左侧一个折叠按钮（汉堡 / 展开图标切换），宽屏随时可点。
- 形态存进设置项 `ui.sidebarCollapsed`（布尔，缺省 false），与「高级操作」同一套接线，换设备记得住。

## 2 窄屏（<1024）

- 侧栏**默认不占位**：主区满宽。
- 顶部一条窄栏：左侧汉堡，中间当前页名字（实例总览 / 维护 / 日志 / …），右侧留空。
- 点汉堡：侧栏以**覆盖层**从左侧滑出，底下加遮罩；点遮罩、按 Esc、点任意导航项都收；打开时焦点进第一个导航项，收起后焦点回汉堡。
- 覆盖层宽度 `min(280px, 78vw)`，不挤压主区。
- 窄屏的开关状态不持久化（每次进来都是收起的）。

## 3 与既有覆盖层的关系

- 侧栏覆盖层 z-index 低于详情抽屉与右侧栏（它们更靠内容），高于遮罩底下的页面。
- 侧栏覆盖层打开时，全局提示位置不变（它固定贴视口底部居中，不动）。

## 4 验收

1. 390 宽：主区宽度 = 视口宽，总览卡片名不再小于 40px，关于页的值不逐字竖排，日志正文可读。
2. 390 宽：点汉堡 → 侧栏滑出且页面不横向滚动；Esc / 遮罩 / 点导航项三种都能收；焦点按验收走。
3. 1280 宽：折叠后主区变宽，侧栏只剩图标；刷新后仍是折叠（读了设置）；悬停图标出名字。
4. 768 宽：落在窄屏那一档，行为同 390。
5. 设置项 `ui.sidebarCollapsed`：GET 缺省 false、PUT 切换后读数变、抽屉与设置页两处不冲突。

不用破折号。
