# 手动启动 dsh（静态说明，不经过网页渲染）

控制台起不来、或者你不想点界面时，照着这里敲。三条命令里的值从控制台的读数里抄：

| 要填的 | 从哪儿抄 |
| --- | --- |
| `<home>` | 抽屉「配置 home」那一格的路径；多数是本机的 `~/.dsh` |
| `<profile>` | 卡片上的名字（不含端口） |
| `<dsh 包目录>` | 关于页「版本」那行悬停里的包目录，或「设置 → dsh 版本」里选中的那一份 |

## 1 稳定环境（用 PATH 上那一个 dsh）

```bash
DSH_HOME=<home> dsh --profile <profile> --no-open
```

这条起的是 PATH 上的 dsh，换版本就是换 PATH 上的那一只。

## 2 锁版本（直接用某个包目录里的入口）

```bash
node <dsh 包目录>/lib/bin.js --profile <profile> --no-open
```

环境里换了版本也不影响它；控制台「用这一版」钉的就是这一份。

## 3 隔离过的那只 profile

把 `DSH_HOME` 换成它自己的隔离 home 路径即可（抽屉「配置 home」那一格写着路径），其余不变。

## 备注

- `--no-open` 是「不要自动开浏览器」；不加的话 dsh 会尝试打开默认浏览器。
- 端口由 dsh 自己挑（控制台起实例时会显式给 `--port`，手动起不必）。
- 这套说明与「关于」页那一块是同一份内容；现在只维护这个文件。
